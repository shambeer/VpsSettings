Эти файлы присутствовали в исходном репозитории и сохранены без изменений. Их версии и соответствие текущему серверу не подтверждены. Они относятся к [прежнему установщику](../scripts/legacy/install.sh) и не считаются полной резервной копией современной конфигурации.
