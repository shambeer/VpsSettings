# VPN-сервер Shambeer

Настройки и история обслуживания VPS `185.22.173.237`. Последнее подтверждение работы VPN: 22 ноября 2026 года.

## Что работает

| Подключение телефона | Проверенный профиль | Результат |
| --- | --- | --- |
| Wi-Fi | XRay-Firefox-WiFi, VLESS/REALITY, TCP 443, fingerprint firefox | Пользователь подтвердил открытие сайтов. |
| Мобильный интернет | Исходный XRay, VLESS/REALITY, TCP 443, fingerprint chrome | Пользователь подтвердил открытие сайтов. |
| AmneziaWG | UDP 46872 | Работоспособность не восстановлена. |

Firefox через мобильную сеть и долговременная стабильность отдельно не проверялись. Для рабочего результата XRay новый VPN не устанавливался; менялся только клиентский fingerprint отдельного профиля. Подробности: [проверки VPN](docs/reports/vpn-working-path-20261122.md).

## Что выполнено на сервере

- Удалены три остановленных контейнера мониторинга и пять отдельно согласованных пакетов после резервного копирования.
- Обновлены 30 пакетов ОС; после перезагрузки используется ядро 7.0.0-43. Три phased-обновления отложены Ubuntu.
- 3x-ui обновлён до 3.11.0. Исправлены TLS Hysteria и источник настроек в 3DP; установлен hook доставки сертификата при продлении.
- Backend/frontend 3DP обновлены после проверки на изолированных копиях. Образы закреплены digest, старые контейнеры сохранены для отката. PostgreSQL оставлен на 18.6.

Это сведения о завершённых операциях, а не результат нового подключения к серверу при уборке репозитория. История и ограничения: [обслуживание сервера](docs/reports/server-maintenance-plan.md).

## Что осталось

- AmneziaWG не исправлен.
- У 3x-ui в bridge опубликована только панель 2053/tcp; его динамические VPN-порты не опубликованы. Это отдельный контейнер от работающего Amnezia XRay.
- Проверка и при необходимости обновление оставшихся образов и итоговый анализ сервера не завершены. Новый [сценарий миграции](scripts/migration/README.md) создан с режимами новой установки, полной копии и переноса; проверен локально, но полный запуск на чистом VPS ещё не испытан.
- Старый [install.sh](scripts/legacy/install.sh) не является средством восстановления текущего сервера.

Домен `servicevps.shamberservice.com` используется этим VPS и сертификатом панели 3DP. Основной `shamberservice.com` указывал на другой сервер; DNS в ходе работ не менялся. Это последний сохранённый результат проверки, а не постоянная гарантия состояния DNS.

## Приватные материалы

Для владельца и раздачи созданы два независимых пользователя XRay: private-vpn/configs/personal/ и private-vpn/configs/shared/. В каждой папке есть connection.txt для вставки ключа в Amnezia, client.json и инструкция. Раздавать только shared/. Оба доступа прошли серверные HTTPS-тесты; на телефоне новые UUID ещё не проверены. [Подробности создания](docs/reports/separate-access-20261122.md).

Рабочие ссылки находятся локально в `private-vpn/configs/original/xray-phone-firefox-link.txt` и `private-vpn/configs/original/xray-phone-link.txt`. Они содержат доступ к VPN. JSON, QR, дампы, ключи и журналы из private-vpn/ не публикуются. Исключение из Git не шифрует файлы.

Все изменения сервера согласовываются с владельцем перед выполнением. При этой уборке сервер не затрагивался; файлы не удалялись, коммиты и отправка в Git не выполнялись.
