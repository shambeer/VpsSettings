# Работа с этим репозиторием

В начале новой сессии прочитай только [краткий контекст](docs/agent-context.md) и проверь `git status --short`. Не перечитывай весь репозиторий и историю отчётов: открывай конкретный источник по указателю из памятки, если он нужен для текущей задачи.

Памятка описывает последнее известное состояние, а не гарантирует текущее. Перед действиями с сервером перепроверь относящиеся к ним факты. Актуальные указания пользователя главнее памятки.

После существенного завершённого изменения обновляй памятку кратко: дата, результат, ограничения, ссылка на подробности. Не переноси в неё ключи, ссылки доступа, дампы и длинные журналы.
