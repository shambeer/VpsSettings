# VPS Migration

Общий интерактивный установщик и мигратор VPN для чистого Linux VPS. Запускайте его на своём компьютере с SSH-ключом. Клонирование репозитория не требуется.

## Запуск одной командой

Windows PowerShell 5.1+:

```powershell
& ([scriptblock]::Create((New-Object Net.WebClient).DownloadString('https://github.com/shambeer/VpsMigration/releases/latest/download/run.ps1')))
```

Linux/WSL:

```bash
curl -fsSL https://github.com/shambeer/VpsMigration/releases/latest/download/run.sh | bash
```

Нужны Python 3.11+ с актуальными исправлениями tarfile и OpenSSH. Для Linux также нужны curl и Bash. Запускатели проверяют SHA-256 Python-пакета перед исполнением; сам скачиваемый запускатель требует доверия к владельцу репозитория и GitHub. При необходимости сначала скачайте и прочитайте его. Временный пакет удаляется после завершения; результаты остаются в выбранной локальной папке.

Для проверки без SSH добавьте `--check` в конец PowerShell-команды. В Linux используйте `curl -fsSL https://github.com/shambeer/VpsMigration/releases/latest/download/run.sh | bash -s -- --check`.

## Что будет дальше

1. Выберите новую установку, перенос из полной копии либо создание копии.
2. Введите адрес VPS, SSH-порт и локальный путь к приватному SSH-ключу. Содержимое ключа на сервер не отправляется.
3. Укажите домен с A-записью на IPv4 входа (relay либо основного VPS) без AAAA, HTTPS-цель REALITY и сетевой профиль.
4. Подтвердите BACKUP/DEPLOY и, для российского сервера, RELAY с его адресом. Для цели нужен чистый Linux x86_64: Ubuntu 24.04/26.04 или Debian 12/13, systemd, root по ключу и Python 3.11+.

**Режимы подключения:** 1 — один VPS без российского сервера; 2 — российский relay + основной VPS (по умолчанию). В обоих режимах устанавливаются прежние XRay/REALITY, AmneziaWG, Telegram-прокси, 3x-ui/3DP и резервные WireGuard, OpenVPN, Shadowsocks, Hysteria2. Сверху добавляются Self-Steal, VLESS TLS/XHTTP, сайт и отдельный Hysteria2 на TCP/UDP 443. PostgreSQL сохраняется; новые доступы экспортируются отдельно с префиксом selfsteal-.

Мастер запросит SSH-доступы к обоим VPS, использует ProxyJump для основного сервера и попросит отдельные DEPLOY/RELAY-подтверждения. Ключи остаются на компьютере. Домен должен указывать на российский relay или, в режиме одного VPS, на основной сервер. Скрипт настраивает перенаправление, сохранение правил, защиту входа основного VPS и проверяет новые подключения через публичный вход. На обоих VPS настраиваются Fail2ban и SSH по ключу с таймером отката. Relay должен быть чистым, с отдельным SSH-портом; DNS и firewall провайдера необходимо подготовить самостоятельно.

Профиль `all` по умолчанию сохраняет доступность старых VPN-портов; это сохраняет и их сетевые признаки. Для минимального публичного набора выберите `filtered`: TCP/UDP 443, SSH и HTTP для сертификата, остальные старые VPN и панели локальны. Модули relay.py, selfsteal.py, topology.py и console.py отвечают за отдельные части схемы.

Выберите каталог: **1 — Рабочий стол, 2 — Документы (по умолчанию), 3 — свой путь**. Все результаты — в `<выбранная папка>/VpsMigration/<дата-id>/`. Бэкап — `migration-bundle.tar.gz`, контрольная сумма — в `backup-result.json`. Личные и общие конфиги/строки — отдельно в `access/personal/` и `access/shared/`. Полный путь показывается до подключения и после завершения; прежние бэкапы не перемещаются. `admin/` и `legacy/` не раздавайте другим пользователям. Резервные копии и доступы не загружаются в GitHub.

Relay не расшифровывает трафик; дополнительного шифрования и ограничения полосы нет. SNI-маршрутизатор пересылает TCP внутри основного VPS. Скорость и доступность зависят от VPS и сети. Публичный IP входа (relay либо основного VPS) остаётся видимым и тоже может быть заблокирован. Полная установка/восстановление и новая цепочка двух Linux VPS ещё требуют сквозного испытания; сначала используйте тестовый сервер.

Подробные требования, пути, резервные копии, доступ к панелям и ограничения: [инструкция](scripts/migration/README.md). Исходники находятся в scripts/migration/. Локальная проверка: `python -m unittest discover -s scripts/migration/tests`.
