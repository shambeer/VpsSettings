# Серверные сценарии

| Файл | Назначение | Состояние |
| --- | --- | --- |
| [migration/migrate.py](migration/migrate.py), [инструкция](migration/README.md) | Интерактивная новая установка, полная копия и перенос нынешнего стека с резервными WireGuard/OpenVPN/Shadowsocks/Hysteria2, защитой SSH и экспортом доступов. Есть deploy.sh и deploy.ps1. | Создан; проверен локальными тестами. Полный запуск на чистом VPS ещё не испытан. |
| [certificates/renew-3x-ui-cert.sh](certificates/renew-3x-ui-cert.sh) | Проверяет и доставляет сертификат servicevps.shamberservice.com в bind-каталог 3x-ui. Перезапускает работающий контейнер только при изменении сертификата; --copy-only выполняет только доставку. | Проверен при настройке TLS. На сервере установлен как Certbot deploy hook 60-3x-ui-domain-cert.sh. Реальное продление ACME не репетировалось. |
| [legacy/install.sh](legacy/install.sh) | Прежняя установка 3x-ui и MTProxy из Docker-архивов. | Исторический исходник. Меняет систему и firewall, удаляет рабочий каталог; не соответствует текущему серверу. Для восстановления не запускать. |

Новый сценарий миграции требует собственной полной копии format=1; старые архивы отдельных операций напрямую не подходят. Операционные Python-сценарии прошлых завершённых работ сохранены локально в private-vpn/server-settings/scripts/ вместе с приватными материалами; они не являются универсальными установщиками.

Изменение или запуск серверных сценариев требует согласования владельца. Эта документация не является поручением их выполнить.
