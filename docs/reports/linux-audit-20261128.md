# Linux-аудит мигратора — 28.11.2026

Проверены локальные регрессии и односерверные Linux-компоненты; это не полное подтверждение всех сценариев миграции.

## Подтверждено

- 122 локальных теста проходят, включая сохранение --low-memory при resume.
- Готовые 3x-ui/3DP/PostgreSQL: запуск, вход и защищённый API3DP.
- XRay, TLS/REALITY/XHTTP и Hysteria2: HTTPS для обеих ролей.
- Sub-Store: raw-подписки, общая страница, manifest и ZIP сверены с экспортом.
- AWG/WG/OpenVPN/Shadowsocks/Telegram: контейнеры запускаются; клиентские сетевые проверки этих протоколов ещё не выполнены.
- Самодостаточная копия15контейнеров: внешний SHA256 и9внутренних контрольных сумм сверены.

## Исправления

1. Обновление grub-pc заранее останавливается при устаревшем пути диска в debconf; загрузочный диск не подменяется автоматически.
2. Родительский каталог PostgreSQL18 допускает проход к закрытому PGDATA; административные доступы сохраняются до запуска панелей.
3. При возврате сервисов после резервирования Sub-Store запускается перед Nginx.
4. Экспериментальный --low-memory сохраняет обе панели и требует около1ГБRAM плюс настроенные2ГБswap; обычный порог1,5ГБ не меняется.

Дальнейшие испытания остановлены по просьбе владельца. Подробная матрица каждого FR, журналы и резервные копии конкретного сервера находятся только в private-vpn/ и не публикуются.

## Дополнительные проверки после продолжения

- AWG, WireGuard, OpenVPN и Shadowsocks: реальные IPv4 HTTPS-запросы для обеих ролей прошли до и после перезагрузки. WG/AWG подтвердили свежие handshake. Использовались временные контейнерные клиенты. Это не испытание импорта на телефон, DNS-настроек клиента или IPv6.
- Telegram: встроенная проверка `ready` прошла. Подключение через настоящий Telegram ещё не проверено.
- SSH-hardening: новый вход по ключу подтверждён, таймер отката отменён. Fail2ban и контрольная перезагрузка проверены. Все 15 сервисов вернулись; API 3DP, прокси и HTTPS-выдача повторно проверены.
- Малый функциональный сценарий: четыре параллельных клиента, 48 HTTPS-чтений и три проверки входа/API 3DP — без ошибок. Большая нагрузка, 500 клиентов и пропускная способность канала этим не измерялись.

### Что означает low-memory

Флаг не урезает панели и не вводит ограничитель полосы. Порог 1,5 ГБ является консервативной проверкой установщика. Небольшой функциональный сценарий успешно выполнен на 1 ГБ с 2 ГБ swap. Это не гарантия для любой нагрузки. Docker показывает рабочий набор памяти контейнера; часть страниц может находиться в swap, поэтому одно число из `docker stats` не описывает всю потребность приложения.

Полные измерения, параметры конкретного VPS и подробная матрица FR сохранены только приватно.
