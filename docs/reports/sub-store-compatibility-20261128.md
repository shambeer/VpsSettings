# Проверка серверного агрегатора Sub-Store

28.11.2026. Backend 2.44.31, [исходники d0bf093c186f3573e3571ae537c5cf6683d72e61](https://github.com/sub-store-org/Sub-Store/tree/d0bf093c186f3573e3571ae537c5cf6683d72e61).

## Метод

Настоящие ProxyUtils.parse/produce испытаны локально на 15 искусственных образцах для URI, ClashMeta, sing-box и JSON. Шесть VLESS URI сгенерированы нашими функциями для TLS/REALITY, XHTTP и WARP; отдельно Amnezia XRay, Shadowsocks, Hysteria2, WG, AWG (объект/URI), OpenVPN (текст/объект), Telegram. Заполнители ключей не являются действующими доступами. Зависимости устанавливались с отключёнными lifecycle-скриптами. Node24.15.0, upstream рекомендует24.22.1. Это проверка преобразования, без сетевого подключения к VPN, запуска Docker/frontend/backend-сервиса или импорта на телефон.

## Результаты

| Элемент | Наблюдение |
| --- | --- |
| Amnezia XRay | URI разбирается/экспортируется. |
| TLS/REALITY RAW и WARP | URI разбираются/экспортируются; сетевое подключение после преобразования не проверялось. |
| TLS-XHTTP и REALITY-XHTTP | URI/ClashMeta выдаются; sing-box-вывод пропускает узел (unsupported network xhttp). В URI меняются типы части XMUX (0 → строка), опускаются пустые headers/uplinkDataKey. Это не доказанная поломка, но не побайтовое сохранение. |
| Shadowsocks, Hysteria2 | URI разбираются/экспортируются. |
| WireGuard | Объект принимается; выдаётся URI/ClashMeta/sing-box. |
| AmneziaWG | URI с плоскими jc/s/h разбирается, но sing-box теряет специальные параметры. Объект amnezia-wg-option сохраняется в ClashMeta; URI сериализует вложенный объект как [object Object], sing-box его опускает. Полная матрица AWG3.1 не испытана: обнаруженных потерь уже достаточно для отказа от безусловной конвертации. |
| OpenVPN | Минимальный исходный OVPN не распознаётся. Mihomo-подобный объект принимается/выдаётся в ClashMeta, но URI/sing-box не содержат узел. Настоящие сертификаты и трафик не испытывались. |
| Telegram MTProxy | tg://proxy не распознаётся как VPN-узел. |

## Вывод

Sub-Store пригоден как кандидат для управления совместимыми коллекциями/хранения файлов, но не подтверждён как готовый конвертер всего нашего набора без потерь. Сборщик должен сохранять исходные строки/файлы; опасные преобразования запрещены. Для AWG/OpenVPN нужны проверенный целевой формат и адаптер; Telegram остаётся отдельной кнопкой общей выдачи. Неподдержанные элементы должны отражаться в manifest, а не исчезать.

Успешный разбор отдельного узла не доказывает импорт смешанной подписки. FR-36–FR-43 пока не реализованы. Реальный VPS и публикации не менялись. До установки — проверка целевого формата/клиента и отдельное согласование VPS-действий.

Локальные доказательства исключены из Git: private-vpn/server-settings/research/sub-store-validation/backend/{compatibility.cjs,compatibility-input.json,compatibility-result.json,compatibility-log.txt}. Сторонние исходники и node_modules не публиковать.
