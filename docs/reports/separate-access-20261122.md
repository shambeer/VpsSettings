# Личный и общий доступ XRay

22 ноября 2026 года пользователь разрешил добавить двух пользователей в существующий Amnezia XRay и подготовить отдельные конфиги для себя и остальных. Применение согласовано с возможным кратким прерыванием VPN.

## Что создано

Приватный каталог private-vpn/configs/:

- personal/ — пользователь Shambeer-Personal, только для владельца;
- shared/ — пользователь Shambeer-Shared, для раздачи остальным.

В каждой папке находятся connection.txt, client.json и инструкция README.md. UUID двух пользователей различаются и не совпадают с прежними. Протокол VLESS/REALITY, TCP 443, flow xtls-rprx-vision, fingerprint firefox. Публичный ключ сервера, SNI и прочие параметры подключения сохранены. Общая серверная криптографическая конфигурация не означает общий пользовательский UUID.

## Применение и сохранность

До изменения сохранены server.json, clientsTable, метаданные контейнера и права файлов. Архив private-vpn/server-settings/backups/vpn/xray-before-separate-users-20261122.tar.gz проверен на чтение всех JSON. SHA-256 серверной и локальной копий совпал: ec2c8d4ae07268ca5641e56e7b45eaa584b972d8ca5b91e907949c4e0c128210.

Первичная проверка кандидата через /dev/stdin потребовала явного -format json: без него Xray не определил формат. После исправления кандидат успешно проверен до изменения рабочих файлов. Три прежние записи сохранены, две добавлены; таблица Amnezia clientsTable синхронизирована с серверной конфигурацией. Применение в 12:29 по Москве сопровождалось перезапуском только amnezia-xray. Остальные шесть рабочих контейнеров не заменялись и не перезапускались. Подготовлен возврат исходных файлов на случай ошибки, но он не потребовался.

## Проверки

- Xray принял серверную конфигурацию; процесс работает после перезапуска.
- Личный и общий файлы ссылок соответствуют их JSON, оба используют firefox и разные идентификаторы.
- Через каждый доступ временный Xray-клиент выполнил HTTPS-запросы к example.com и Cloudflare trace: HTTP 200, внешний адрес VPS подтверждён. Временные контейнеры удалены; при тестах рабочая конфигурация и время старта не менялись.
- Новые файлы исключены из Git. Секреты в этот отчёт не включены.

## Как раздавать и отзывать

Владельцу использовать personal/connection.txt. Остальным передавать только shared/ или его connection.txt, не весь configs/. Общий доступ независим от личного, но внутри shared все используют одну учётную запись. Её отзыв отключит всю группу; для индивидуального отзыва потребуются отдельные пользователи. Отзыв, удаление прежних пользователей и новые изменения сервера этим шагом не выполнялись.
