## Машинные результаты

| Каталог | Что содержит | Ключевой результат |

| evidence/inventory/ | Инвентаризация, DNS, аудит публикации портов. | [Аудит сети](evidence/inventory/post-tls-network-audit.json) |

| evidence/vpn/ | Проверки резервной копии VPN и функциональный тест XRay. | [Тест XRay](evidence/vpn/xray-functional-test-20261122.json) |

Здесь сохранены также неуспешные промежуточные проверки. Наличие файла с result/check в имени само по себе не означает успех: смотрите содержимое и описание соответствующего этапа. JSON фиксируют состояние в момент проверки, а не выполняют повторную проверку сервера.

Приватные исходники, дампы, журналы и метаданные с доступами находятся только в исключённом из Git private-vpn/.
