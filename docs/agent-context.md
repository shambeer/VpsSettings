# Контекст проекта для агента

Проект содержит интерактивный мигратор и переносимый запускатель. Публичная инструкция: [scripts/migration/README.md](../scripts/migration/README.md).

Мигратор организован как scripts/migration/vps_migration/: cli/ — мастер, ввод и схема; core/ — общие функции; server/ — VPN, relay, Self-Steal, бэкапы и worker; packaging/ — переносимая сборка и templates/. Корневые migrate.py, remote.py и build_portable.py — совместимые точки входа. Прежний VPN-набор и PostgreSQL сохраняются. Новый Self-Steal добавляется сверху. Перед запуском требуется проверить DNS, отдельные SSH-доступы и подтверждения для обоих VPS. Полная цепочка двух Linux VPS ещё требует сквозного испытания; локальные тесты этого не заменяют.

Если локально существует private-vpn/server-settings/agent-context.md, прочитай его для продолжения работы с конкретным сервером. Если файла нет, используй только общую документацию и текущий запрос пользователя. Не подключайся к серверу автоматически.

Карта возможностей и ограничений: [functional-requirements.md](functional-requirements.md). Обнаруженный аудитом блокер защиты SSH relay исправлен: security_prepare выбирает deploy-result.json для основного VPS и relay-result.json для relay, требует булев success=true. Регрессионный тест проходит от результата настоящей функции relay.install до подготовки и подтверждения SSH с изолированными системными вызовами. Это не заменяет полное испытание двух Linux VPS.

Сведения об адресах, доменах, отпечатках SSH, действующих профилях, инвентаризации и результатах обслуживания хранить только в private-vpn/. Не переносить их в публичный AGENTS.md или README. Не считать старые записи подтверждением текущего состояния.

Развёрнутые пояснения сохранять в файлы, в чате оставлять короткий итог. Изменения серверов требуют предварительного согласования. Локальные тесты: python -m unittest discover -s scripts/migration/tests. Сквозная проверка на чистом VPS ещё требуется.

FR-33/FR-35: cli/maintenance.py и server/maintenance/ реализуют согласованные APT dist-upgrade и выборочную очистку Docker/APT (пункт 4), копии /etc/образов, проверки планов, отдельную перезагрузку. Обновление ОС также входит в установку обоих VPS. FR-34 по уточнению пользователя не расширять: обновления 3x-ui/3DP остаются штатным механизмам, major PostgreSQL автоматически не менять. Архивы обслуживания не являются format1 bundle или образом ОС; тома сохраняются, но не архивируются этой очисткой. Linux E2E не выполнялся.

FR-11: приоритет Amnezia → новые способы → остальные; все разные варианты остаются. Amnezia XRay напрямую на 443, новые способы на отдельном TCP/UDP-порту 8443 (выбор при восстановлении в cli/topology.py). exposure_bindings переносит только новый вход; restore_shared_edge возвращает известную старую публикацию Amnezia loopback1443 на443. Новая установка с Self-Steal не создаёт vpn-hysteria2 в дополнение к vpn-selfsteal-hysteria2; сохранённые контейнеры/доступы из копии не удаляются. Полная существующая схема не создаётся повторно. Произвольная семантическая дедупликация сторонних конфигураций не реализована. Проверки и firewall/relay используют отдельный порт. Linux E2E ещё требуется.

FR-07: cli/session.py хранит приватный журнал session.json с ответами/контрольными точками; --resume требует RESUME и ту же версию кода. Мастер восстанавливает полный сценарий, включая backup→migration, оба VPS, обслуживание и ожидание reboot. Успешные эффекты/загрузки пропускаются; скачивания повторяются атомарно с SHA256. server/execution.py ставит постоянную отметку перед background-задачами, не даёт выполнить их второй раз; systemd unit/результат позволяют повторно наблюдать после потери SSH/ответа запуска. Нет автоматического повторения частично упавшей серверной задачи после аварии ОС. SSH hardening можно продолжить после таймера отката с новым таймером; boot-ID reboot сохраняется. Журнал содержит параметры и пути к SSH-ключам, не ключи. Старые запуски без session.json не восстанавливаются. Linux E2E ещё требуется.

FR-17: full_selfsteal по умолчанию в новых установках/миграциях; core/selfsteal_options.py, cli/selfsteal.py, server/selfsteal_features/ (install, profiles, warp, subscriptions, certificates). Амнезия напрямую443; TLS/XHTTP/WARP/Hysteria2 на8443, REALITY/Reality-XHTTP/Reality-WARP на8444; все разные варианты, без новых контейнеров WARP. Регистрация по API Cloudflare из 3x-ui, кэш на IP, pending не повторять, только WARP-tag через userspace WireGuard. Статический сайт --options/site_directory, расширенные XHTTP/extra, SAN, HTTPS-подписки/token по роли + Happ/INCY routing; whitelist явно. HTTP80 для redirect/ACME, Certbot webroot (2.3+ reconfigure; старый: dry-run+force renewal). Полный режим требует Xray26.11.9+/Nginx1.25.1+. Параметры сохранены для FR-07 resume. Новые профили standalone, FR-24 не расширен; не заявлять автоинбаунды 3x-ui/3DP. Локально 6 VLESS+2 HTTPS-подписки через настоящие Xray/Nginx прошли с тестовым выходом вместоCloudflare; реальные WARP/ACME/Linux/телефоны не испытаны. Сверены текстовый гайд и главы видео; субтитры пусты, аудио целиком не проверено.
