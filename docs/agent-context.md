## Правила взаимодействия

- Русский язык. В чате короткие статусы и итог; развёрнутые пояснения и документы сохранять в этом репозитории. Пользователь уже выбрал этот режим — повторно не спрашивать.

## Незавершённые задачи и ограничения

1. AmneziaWG не исправлен. Для уже работающего XRay это не требуется.
2. 3x-ui работает в bridge и публикует только панель 2053/tcp; его динамические VPN-порты не опубликованы. Это не контейнер Amnezia XRay. 3DP меняет порты в диапазоне 10000–59999; его прежний allocator не проверял занятость портов процессами хоста. Не переключать host network и не открывать весь диапазон без отдельного плана и согласия.
3. Проверка/обновление оставшихся образов и итоговый анализ не завершены. Новый сценарий миграции создан, но полного испытания на чистом VPS пока нет; см. ниже. scripts/legacy/install.sh для восстановления не использовать.

## Быстрое продолжение

22 ноября создан [сценарий миграции](../scripts/migration/README.md), точка входа scripts/migration/migrate.py, обёртки deploy.sh/deploy.ps1. По выбору пользователя поддерживаются новая установка и сохранение доступов из копии, плюс самостоятельный backup. Включены нынешние семь сервисов и резервные WireGuard/OpenVPN/Shadowsocks/Hysteria2. Новые панели пустые: динамические подписки/inbounds автоматически не создаются. Копия должна быть создана этим сценарием (format=1, образы+тома+bind), старые частные tar.gz не подходят. При копировании ротация приостанавливается, сервисы останавливаются по зависимостям и возвращаются в finally. Backup/deploy запускаются через systemd и переживают обрыв SSH. Ключ вводится как локальный путь, не передаётся серверу. Key-only SSH и Fail2ban применяются после проверок, с таймером отката SSH и повторным входом. Результат: private-vpn/server-settings/migrations/<id>/access/{personal,shared}/{configurations,strings}/ плюс admin/legacy. Условия: чистый Linux x86_64, Ubuntu 24.04/26.04 или Debian 12/13, root по ключу, Python 3.11+, домен A→новый IP без AAAA. Ничего на серверах при разработке не запускалось. Локальные тесты и синтаксис проверены; E2E, продление ACME и проверка всех новых протоколов на устройствах ещё требуются. Не объявлять этот сценарий испытанным восстановлением.

Текущая структура после пользовательского переноса: архивы в private-vpn/server-settings/backups/{3dp,3x-ui,system,vpn,monitoring,failed}/; Остальные пути относительно private-vpn/server-settings/: настройки-снимки в settings/{3dp,amnezia}/; метаданные в metadata/ по компонентам; журналы в logs/; разовые Python-сценарии в scripts/{3dp,xray,repository}/. Прежние xray-phone* перенесены в configs/original/. Папки private-vpn/configs/personal/ и private-vpn/configs/shared/ оставлены отдельно; for-distribution/ перенесена пользователем внутрь private-vpn/server-settings/. Все 61 перемещённый файл проверены по SHA-256; ничего не удалено, сервер не менялся. Приватный индекс: private-vpn/README.md. Исторические сценарии не адаптированы для повторного запуска из новых каталогов.

Прочитать эту памятку → проверить Git → определить согласованный объём → открыть только нужные файлы. Для локальной документации не подключаться к серверу без необходимости. Перед существенным серверным действием получить разрешение и проверить актуальные конфигурацию и резервную копию; старый отчёт не является доказательством текущего состояния.
